What is shipping?

Shipping your project means sending it off to the world for others to experience! For Atlantis, that means having a good-looking Printables page with a great description that accurately describes what your project is and how it works, along with a .step file and an editor file such as a .f3d.

How do I get my project ready for shipping?

For Atlantis, there are a few requirements for shipping. You can check them out in the Project Guidelines, and make sure your project conforms to all of them.

Can I ship one project multiple times?

Yes! You can ship as many times as you want — but each ship must have considerable and noticeable changes from the last. Each new ship will give you more currency and hours put towards your printer and other rewards in the shop.
