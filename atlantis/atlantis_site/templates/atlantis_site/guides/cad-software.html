CAD Software

Many CAD packages are available and all work differently. Choosing one depends on your use case and preferences — if you haven't picked one yet, this might help!

You may use Fusion 360, Onshape, Solidworks, or FreeCAD. Blender is not allowed.

AI CAD is strictly prohibited.

Choosing a software

Below is a breakdown of Fusion 360, Onshape, and Solidworks. These three are some of the most popular options and are widely used for both hobby and industry CAD.

Fusion 360

First things first, Fusion runs heavily off your computer's hardware, so if you don't think yours can handle it you might want to skip this one. It also isn't available for Linux.

Fusion 360 is unique (among the three) in its hybrid part creation and assembly system. You create parts and arrange them into an assembly in the same document/file; this can be useful for making changes based on other elements, and is good for projects without tons of parts. You are also able to make part designs and assembly designs separately, though it isn't necessarily as intuitive as Onshape.

The UI of Fusion is also more clean and updated than Onshape's and Solidworks', in my opinion, though that's more preference based. It has a dropdown tool menu which can prove a lot less overwhelming and intimidating for beginners.

You can find the form to apply for a Fusion 360 student license here.

Onshape

This is a very popular option, especially for Linux users — I tend to see a 50/50 split between Onshape and Fusion users. Onshape is a web based CAD package, so if your computer isn't very powerful you can still run it. Also, because it's a web based program, it can run on any OS including Linux.

All files for Onshape use cloud storage rather than local, but that also means it requires internet to use. The toolbar is much less compact than both Fusion's and Solidworks', which can be overwhelming for a beginner, but like anything you get used to it if you use it enough.

Onshape also excels at team and group projects with its ability for multiple people to work on the same document simultaneously.

Public projects on Onshape are all searchable and usually can be copied, which lets you edit them for the needs of your projects. This also allows you to insert hardware, motors, or other off-the-shelf parts that other people have added without having to download a file and insert it from an external source.

Onshape versions let you go back to a previous state of your CAD if something drastic ever has to be changed. The version function also offers a GitHub-like tree feature that allows for multiple different states of a CAD to exist at once.

You can use Onshape entirely free without a student account.

Solidworks

A less popular platform for hobbyists, but widely used in industry for mechanical engineering. Like Fusion 360, files are stored on the device and it runs heavily off your computer's hardware, and it is not available for Linux.

Solidworks is very similar to Fusion 360, though its UI is older and it has a lot more industrial-type features. It's also built for bigger assemblies, and has sheet metal and simulation capabilities (as does Fusion). Solidworks is a bit more difficult for beginners, but it is a very solid (pun intended) choice overall.
