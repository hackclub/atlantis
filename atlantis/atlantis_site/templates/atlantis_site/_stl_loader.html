{% comment %} The 3D model viewer, fetched only when a model is actually wanted. three.js and its loaders are several hundred KB off a CDN, and most visits to a page that could show a model never open one, so nothing here downloads them up front. window.atlantisSTL() resolves to the viewer module (its `init(container)` mounts a viewer on a box with a data-stl-url); the first call fetches it, every later one shares that fetch. Viewers made on demand (the book's close-up slip, the profile's "View STL") call it when they open. Viewers already in the markup are started as they come within 200px of the window, so a review page with a dozen collapsed journals opens no WebGL context until one is shown. The import map costs nothing until something imports "three", so it stays. {% endcomment %} {% load static %}
