{% comment %} One popup for every "View address" button on the page, so looking one up never reflows a table. Any `.view-address-btn` is wired to it: data-url the POST endpoint (view_order_address, view_user_address) data-address-label the line under "Ship to": whose address, for what data-address-confirm optional; asked first, and nothing is fetched on a no Fetched on a click rather than a hover: each look is an audit-logged read of someone's address, and a hover would log every passing mouse. Once open, each line is blurred until it is hovered (or focused, for keyboards and taps), so an address on a shared screen isn't read over a shoulder. {% endcomment %}
